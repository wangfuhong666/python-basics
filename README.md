# Python 基础部分

个人学习 Python 时写下的基础语法练习与示例代码合集，按主题分类整理。代码以「把每个知识点亲手敲一遍」为目的，写法偏练习性质，不代表最优解。

## 环境与依赖

- Python 3（开发环境为 3.13）
- 第三方库（仅部分文件需要）：

```bash
pip install pygame pymysql moviepy
```

其余文件只使用标准库（`re`、`functools`、`random`、`decimal`、`unicodedata`、`sys` 等），无需额外安装。

## 运行方式

```bash
python 文件名.py
```

例如：

```bash
python 井字棋AI.py
python 马青公式计算圆周率.py
```
